# 🎓 Education Management Portal with AI Academic Advisor

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/pavithrathiraviyaraj/education-management-portal)

A premium, full-stack educational intelligence platform featuring a React frontend, Node.js Express backend, and a Python FastAPI Machine Learning microservice.

---

## 🚀 One-Click Cloud Deployment (Render.com)

Click the button above or follow these steps:
1. Login to [Render.com](https://render.com) using your GitHub account.
2. Go to **Blueprints** and click **New Blueprint Instance**.
3. Select `pavithrathiraviyaraj/education-management-portal`.
4. Click **Apply**. Render will automatically deploy all 3 services using `render.yaml`.

---

## 🛠️ Architecture Overview

- **Frontend (`/frontend`)**: React 18, Vite, Lucide-React, Recharts, Educational Red & White Theme.
- **Backend (`/backend`)**: Node.js, Express, MongoDB Mongoose, JWT Authentication.
- **AI Microservice (`/ai-service`)**: Python 3.10, FastAPI, Scikit-learn, Uvicorn, Real-time Risk Prediction & Chatbot Engine.
